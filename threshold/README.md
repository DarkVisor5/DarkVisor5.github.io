## Distribuzione
Per pubblicare il gioco su GitHub Pages, caricare la build completa come `threshold/index.html`. La build è un file HTML autosufficiente con grafica e audio incorporati.

GitHub Pages va abilitato nelle impostazioni del repository se non è già attivo: Settings → Pages → Deploy from a branch → main / (root).

Gli aggiornamenti successivi sostituiscono soltanto `threshold/index.html`, lasciando intatto il resto del sito personale.
